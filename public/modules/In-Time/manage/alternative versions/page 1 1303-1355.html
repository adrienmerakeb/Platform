Notification settings
Include desk ID / operator name in visitor reminders
Automatically includes the operator's desk identifier and name in visitor notifications — e.g. "Please proceed to Desk 3 / Window B — Front desk." Useful for multi-desk venues. Applies to all operators on this queue.
Operator accounts
📋 How operator login works: Operators use the host login page — same company name, different email and password. After entering credentials, a verification link is sent to their email. Sessions last 24 hours.
✅ Operators can
  • Call next visitor
  • Scan & validate arrivals
  • Mark no-show
  • View booking details
  • Send messages via queue channels
  • Release batches (wave / flow queues)
🚫 Operators cannot
  • Change slot types or schedules
  • Change capacity or payment settings
  • Change release rules or calendar sync
  • Create or delete queues
  • Access subscription or integrations
🔑 You are responsible for managing operator passwords and access. Set secure passwords and share them directly with each operator. You can update or revoke access at any time from your host account page.

Operator accounts are created immediately when the queue is saved. You can also add, edit, or remove operators from your host account page at any time.
